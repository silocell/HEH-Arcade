# HEH-Arcade

The Arcade from Homework Launchpad, at **arcade.civilinitiatives.org**: Robin Hop,
Catapult Castle, Paper Toss, Penalty Shootout, Paper Plane, Block Drop, Doubles and
Space Rocks. No questions - just games.

Open to accounts that have all games switched on. Everyone else gets the site's
404 page. Sign-in and the games lock come from the main site, civilinitiatives.org.
